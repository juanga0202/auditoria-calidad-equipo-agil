# Diagnóstico ISO/IEC 25010

| Problema observado | Atributo de calidad |
|---|---|
| Defectos que llegan a producción | Fiabilidad |
| Pruebas principalmente manuales | Mantenibilidad |
| Despliegues concentrados los viernes | Fiabilidad |
| Falta de pruebas automatizadas | Mantenibilidad |
| Riesgo de errores en información de pacientes | Seguridad |
| Entregas frecuentes cada dos semanas | Adecuación funcional |
| Correcciones posteriores al despliegue | Mantenibilidad |

## Enfoque

El diagnóstico relaciona cada problema del caso con el atributo de calidad que debe fortalecerse mediante prácticas de desarrollo, pruebas y entrega continua.
