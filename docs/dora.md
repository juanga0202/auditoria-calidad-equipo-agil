# Métricas DORA

Las cuatro métricas principales consideradas para la auditoría son:

| Métrica | Qué mide |
|---|---|
| Deployment Frequency | Frecuencia con la que se realizan despliegues. |
| Lead Time for Changes | Tiempo desde el cambio hasta su despliegue. |
| Change Failure Rate | Porcentaje de despliegues que generan fallos o requieren corrección. |
| Mean Time to Recovery (MTTR) | Tiempo medio necesario para recuperar el servicio después de un fallo. |

## Fórmulas

- Deployment Frequency = número de despliegues / periodo.
- Lead Time for Changes = tiempo entre commit/cambio y despliegue.
- Change Failure Rate = (despliegues con fallo / total de despliegues) × 100.
- MTTR = tiempo total de recuperación / número de incidentes.

Los valores finales se calculan con los datos simulados entregados por el docente.
