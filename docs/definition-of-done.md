# Definition of Done y Kanban

## Definition of Done

Una tarjeta solo pasa a DONE cuando:

1. El código cumple los estándares definidos.
2. Tiene pruebas unitarias automatizadas cuando aplica.
3. Todas las pruebas pasan.
4. Otro integrante realizó revisión de código.
5. Los criterios de aceptación fueron verificados.
6. La documentación necesaria está actualizada.

## Flujo

BACKLOG → TODO → IN PROGRESS → CODE REVIEW → TESTING → DONE

## Políticas

| Columna | Política | WIP |
|---|---|---:|
| BACKLOG | Trabajo identificado y priorizado. | — |
| TODO | Lista para iniciar y con criterios claros. | — |
| IN PROGRESS | Un integrante está desarrollando la tarea. | 2 |
| CODE REVIEW | Revisión por otro integrante antes de probar. | 2 |
| TESTING | Pruebas ejecutadas y resultados registrados. | 2 |
| DONE | Cumple completamente la Definition of Done. | — |
